Start, stop, inspect, and boot systemd-inspired chroot service units from service_dirs.

- Output modes: `human`, `json`

| `--status` | false | false | Show one unit's current status. |

| `--restart` | false | false | Restart one unit. |
| `--logs` | false | false | Print one unit's journal-style log output. |
| `--foreground` | false | false | Run the unit in the foreground instead of spawning it. |
| `--tail` | false | false | When used with --logs, show only the last N lines. |
| `--follow` | false | false | When used with --logs, stream appended journal lines. |
| `--target` | false | false | Target to use with --boot. Defaults to boot.target. |
| `--no-parallel` | false | false | Start boot units sequentially instead of parallelizing independent layers. |
