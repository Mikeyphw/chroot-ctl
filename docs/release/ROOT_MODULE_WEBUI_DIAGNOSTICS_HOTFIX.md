# Root Module WebUI Diagnostics Hotfix

This hotfix releases root module **1.3.4** (`versionCode=19`).

It standardizes the module identity on `chrootctl`, repairs KernelSU WebUI stdout/stderr transport, preserves structured install failure diagnostics and log provenance, and permits same-origin standalone WebUI API requests with an XHR fallback when `fetch` is unavailable or rejected by the WebView/browser transport.

The checked-in compatibility manifest is part of the release identity and must match the module payload generated by `internal/module.CompatibilityPayload()`. The Android app minimum supported module version code for this release is therefore `19`.
