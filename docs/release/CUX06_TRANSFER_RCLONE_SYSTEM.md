# CUX-06 — Transfer, Rclone, System and accessibility

Overlay 6 of 7 completes the product-domain UX before the final seal.

- Transfer explains the single preview/integrity/persistent-operation workflow.
- Rclone is a remote browser/selector and hands locations to Transfer rather than duplicating transfer execution.
- System separates device-local preferences from backend-owned runtime/module state and links diagnostics/logs/maintenance.
- Duplicate global refresh controls are suppressed when a workspace owns a scoped refresh action.
- Rclone failures use human-readable primary copy with technical codes demoted to details.
- Keyboard skip navigation, visible focus, 44px minimum interactive targets, responsive single-column phone layouts and wide-screen bounds are sealed.
- No backend, privilege, transport, HTTP, KSU, or operation contract is broadened.
